# Deployment

This is a static website and requires no build step.

1. Upload `index.html`, `food.css`, and `food.js` to a static hosting provider.
2. Keep the relative file paths intact.
3. Verify the site loads over HTTPS.
4. Test menu card clicks and popup dismissal.
5. Confirm remote image URLs still return images.

A static deployment does not create an order-processing backend. Do not advertise the popup as a real checkout or payment flow.
