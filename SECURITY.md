# Security Policy

## Scope
This is a static frontend demonstration. It does not create real orders or process payments.

## Important limitations
Menu prices and delivery-charge rules are client-side values and can be modified by visitors. Do not treat the popup summary as an authoritative quote or confirmed order.

## Reporting
Do not publish sensitive details in a public issue. Use GitHub private vulnerability reporting when available, or contact the repository owner privately with impact and reproduction steps.

## Production requirements
A real ordering flow requires server-side price validation, order persistence, input validation, authentication where appropriate, secure payment-provider integration, and privacy controls.
